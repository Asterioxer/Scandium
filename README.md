# Scandium

Scandium is a C++ game-systems engineering laboratory focused on high-performance navigation, 3D mathematics, simulation, profiling, and agentic development workflows.

## Roadmap

- [ ] C++20 + CMake foundation
- [ ] Math primitives and transforms
- [ ] Collision and spatial queries
- [ ] A* navigation
- [ ] Multi-agent simulation
- [ ] Performance benchmarks
- [ ] REST live-service prototype
- [ ] Agentic engineering harness
